# GAS + AI ブログ記事自動生成

Google スプレッドシートにキーワードを入れると、AI が SEO 記事の下書きを書き、WordPress に**下書きのまま**保存する仕組みです。

BtoB SaaS のオウンドメディアを想定したサンプル案件です。サイトや製品名は架空のものです。

## 背景と効果

| | 導入前 | 導入後の見込み |
| --- | --- | --- |
| 1本あたり | 3時間 | 30分以下 |
| 週3本の場合 | 週9時間 | 週1.5時間以下 |

AI の下書きは 60〜70点をスタートとし、人が10分ほど手を入れて仕上げる前提です。そのまま公開できる完成原稿を目指すものではありません。

## 流れ

```
スプレッドシート ─→ Google Apps Script ─→ Claude API（記事を書く）
      ↑                    │
      └──── 状態・URL ──────┴─→ WordPress REST API（下書きで保存）
```

1. シートにキーワード、サブキーワード、検索意図を入れる
2. 行を1つ選び、メニュー「記事生成」→「選択した行の記事を作る」
3. タイトル、本文、メタディスクリプション、文字数がシートに入る
4. 「選択した行を下書き保存」で WordPress に下書きとして保存し、URL がシートに入る
5. 公開するかどうかは、人が WordPress の画面で決める

週3本の運用なので、1回に1行だけ動かします。一括生成はしません。

## 使った技術

| 役割 | 技術 |
| --- | --- |
| 操作画面 | Google スプレッドシート |
| 処理 | Google Apps Script |
| 記事の下書き | Claude API |
| 保存先 | WordPress REST API |
| 開発 | clasp でローカルの `Code.gs` を Apps Script に反映 |

## 工夫したところ

- **自動公開しない**：WordPress へ送る状態は `draft` だけ。`publish` はコードのどこにも書いていません
- **上書きしない**：本文がある行や「下書き保存済み」の行は、理由を出して止まります
- **状態を5つに分けた**：記事がシートにあるだけなのか、WordPress にもあるのかを見分けられます

  | 状態 | 意味 |
  | --- | --- |
  | 未生成 | まだ作っていない |
  | 生成中 | 作っている途中 |
  | シート保存済み | シートに保存。WordPress には未送信 |
  | 下書き保存済み | WordPress に下書きで保存 |
  | 失敗 | 理由をメモ列に残し、その行だけやり直せる |

- **文体をそろえる**：見本記事をプロンプトに入れ、トーンを合わせています。見本の言い回しを借りないよう指示しています
- **法令の言い方を最新にする**：AI が古い言い方で書かないよう、最新の法令メモをプロンプトに入れています。それでも、法令・料金の数字とほかのサイトとの類似は、公開前に人が確認します
- **鍵をコードに書かない**：API キーと WordPress の Application Password は、Apps Script のスクリプト プロパティにだけ置きます
- **見本のサイトには送らない**：送り先が見本のドメインのときは、送信せずに止まります

## 動かし方

1. スプレッドシートの「拡張機能」→「Apps Script」に `Code.gs` を入れる
2. `APIキー設定手順.md` のとおり、スクリプト プロパティに次の4つを入れる
   - `ANTHROPIC_API_KEY`
   - `WP_SITE_URL`
   - `WP_USER`
   - `WP_APP_PASSWORD`
3. シートを再読み込みし、「記事生成」→「見出しを用意する」
4. あとは `運用マニュアル.md` のとおり

WordPress の設定が空のときは送信せず、送る予定の `title`、`content`、`status`、`excerpt` を Apps Script のログに出します。

## やらないこと

- 画像の挿入
- 自動公開
- コピペチェックの外部サービスとの自動連携
- 複数本の一括生成
- 法令・料金・他社の数字が正しいかの自動判定
